# 🖼 메인 배경화면 교체 가이드

지금 타이틀(메인) 화면 배경은 **인라인 SVG로 그린 탑 그림**(임시)입니다.
진짜 이미지로 바꾸려면:

1. 이 폴더(`bg/`)에 이미지 파일을 넣습니다. 예: `bg/title.jpg`
   - 권장: 가로로 넓은 이미지(1600×900 이상), jpg/png/webp
2. `js/game.js` 상단의 `MAIN_BG`에 경로만 적습니다:
   ```js
   const MAIN_BG = "bg/title.jpg";
   ```

- 파일이 없거나 로드 실패하면 **자동으로 SVG 배경으로 폴백**되니 깨질 일 없습니다.
- 온라인 배포(Render) 시 서버가 이 폴더를 자동으로 서빙합니다.
- 배경 위 글자가 잘 보이도록, 너무 밝은 이미지는 어둡게 보정하거나 SVG처럼 상하단이 어두운 그림을 권장합니다.
